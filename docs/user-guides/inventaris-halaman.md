# Inventaris halaman dan skenario

Sumber aplikasi `4c341b0b67bbeed0ea366fb22b3d369c47677b39` — 18 Oktober 2026 WIB. Inventaris berasal dari `src/app/**/page.tsx`, shell/navigasi dan modal aktual. Route API bukan menu pengguna. **8 permukaan Admin, 4 menu Pegawai, 1 pintu login bersama**; logout mengembalikan pintu tersebut. Alias profil tidak dihitung sebagai menu baru.

## Halaman yang dapat diakses

| Peran   | Menu/route                  | Tab/modal dan tindakan                                         | Tujuan, batas dan bukti                                                                                                          |
| ------- | --------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Umum    | `/` saat belum login        | Login, gagal login, logout                                     | NIP/password; sesi nyata. Gambar 001–002 dan 052                                                                                 |
| Pegawai | `/dashboard`                | Saldo, ringkasan, Cuti/Izin, filter, kalender/agenda           | Hanya milik sendiri; tanggal kosong bukan eligibility. Gambar 003–005, 046, 049                                                  |
| Pegawai | `/profil`, alias `/#profil` | Profil, preview/save/delete foto                               | Hanya diri sendiri; data master dibaca, tidak ada ganti password mandiri. Gambar 048, 053–057                                    |
| Pegawai | `/pengajuan`                | Cuti/Izin; form baru, draf, detail, revisi, scan, arsip/return | Query `kind=leave/permission`, `new=1` membuka form; tidak membuat record sebelum simpan. Gambar 006–015, 018–021, 047, 050, 078 |
| Pegawai | `/klaim-cuti-bersama`       | Daftar, Ajukan Klaim, bukti/tanggal                            | **Terbatas error HTTP 500**; belum ada screenshot sukses/review/duplikasi. Gambar 016–017                                        |
| Admin   | `/dashboard`                | Ringkasan, nama kalender/agenda, Kelola kalender hari libur    | Data minimal Admin; overlay hanya preview simulasi. Gambar 034–038                                                               |
| Admin   | `/` saat login              | Pegawai, detail/edit, aktif-Arsip, akun, import                | Search/filter/pagination, bukan hard delete; Employee/User terpisah. Gambar 022–033, 051, 077                                    |
| Admin   | `/admin/saldo-cuti`         | Tahun/status/detail, inisialisasi, batch                       | Dasar sah, tidak overwrite/PARTIAL repair; terpisah dari impor Pegawai. Gambar 063–067                                           |

| Admin   | `/profil`, alias `/#profil` | Foto sendiri                                                   | Avatar membuka profil; bukan fitur foto pegawai lain. Gambar 058–062                                                             |
