# Unduh buku panduan SI CUTI

[Unduh ZIP PDF dan Word](si-cuti-panduan-pengguna-2026-10-18.zip?raw=true).

ZIP sekitar 19 MB berisi Panduan Pegawai dan Panduan Admin, masing-masing dalam PDF dan DOCX, beserta hasil validasi dan checksum. Seluruh contoh menggunakan data sintetis.

Di GitHub, buka berkas ZIP lalu pilih **Download raw file** jika unduhan tidak langsung dimulai. Masuk ke akun GitHub yang mempunyai akses repository bila diminta. Setelah selesai, ekstrak ZIP melalui aplikasi Files/File Manager perangkat.

Berkas ini disediakan pada branch dokumentasi setelah PR #119 merged; tidak mengubah staging atau aplikasi yang berjalan. Batas pembuktian panduan, bug klaim, UAT dan render native DOCX tetap mengikuti checkpoint panduan.
