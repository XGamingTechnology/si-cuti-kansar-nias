## Bug lokal: endpoint statis Klaim Cuti Bersama HTTP 500

**Reproduksi pada build sumber, PostgreSQL disposable dan sesi login nyata:**

1. Masuk sebagai Pegawai; buka `/klaim-cuti-bersama`.
2. `GET /api/joint-leave?year=2026` mengembalikan **500**, UI menampilkan “Klaim cuti bersama gagal diproses.” Jangan menafsirkan daftar di bawah error sebagai daftar kosong sah.
3. Buka Ajukan Klaim: pilihan kebijakan tidak berhasil dimuat. Sebagai Admin, form Atur Tanggal Cuti Bersama terbuka, tetapi `POST /api/joint-leave/policies` dengan payload sintetis valid juga **500**. Pengiriman klaim multipart valid pada percobaan lokal sebelumnya juga 500.
4. Sebagai diagnosis, konfigurasi kebijakan simulasi melalui `JointLeaveService.configure` pada DB lokal yang sama berhasil. Ini hanya bootstrap fixture, **bukan bukti endpoint/UI sukses**.

**Dampak:** screenshot klaim tersimpan, bukti tersimpan, review sebagian/penuh dan notifikasi duplikasi tidak tersedia. Tidak memakai mock untuk menggantikannya. Jangan melatih pengguna mengulang pengiriman untuk mengatasi masalah ini.

**Hipotesis dari inspeksi kode, belum dibuktikan stack trace:** `src/application/joint-leave/delivery.ts` mengakses `(await context.params).id` bila `context` tersedia. Static App Route dapat menerima context tanpa `params`; pembacaan itu dapat melempar sebelum service. HTTP factory tests dapat melewatkan kondisi tersebut karena context tidak diberikan. Perlu task perbaikan terpisah beserta integration route nyata. Runtime sengaja tidak diubah dalam PR dokumentasi.
