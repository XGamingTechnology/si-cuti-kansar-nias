# Perbaikan UAT formulir, klaim, izin dan penanda

Sumber: `origin/staging` **e5c1818305e8f50c74bd2fea7e5cb61536a87b09**,
di-fetch dan diverifikasi terhadap remote. Satu branch/task, target PR `staging`.
AGENTS.md, PDF proposal, tujuh dokumen wajib dan keputusan workflow/klaim/arsip/penanda
serta checkpoint 18 Oktober dibaca sebelum perubahan. Data seluruhnya sintetis;
tidak mengakses VPS atau DB staging/produksi. Ini bukan pengesahan UAT VPS.

## Temuan dan perubahan

1. **Formulir PDF:** renderer lama menulis nilai sel tanpa batas lebar, memakai perkiraan
   jumlah karakter, dan membuang sisa alasan/alamat melalui `slice(maxLines)`. Kini lebar
   glyph Helvetica diukur, kata panjang dipecah, tinggi baris mengikuti isi dan baris panjang
   diteruskan pada A4 berikutnya. I–VIII, kolom, urutan, identitas snapshot dan kolom keputusan
   kosong dipertahankan. Data wajar tetap satu halaman; data panjang dapat menambah halaman,
   tanpa menghilangkan ekor isi atau mengecilkan seluruh formulir. Format bukan surat baru.
   Kontrol form memiliki min-width/box-sizing yang eksplisit; tanggal disusun satu kolom
   pada layar kecil. Tidak mengubah aturan pengajuan/saldo.
2. **HTTP 500 klaim:** endpoint statis menerima context Next tanpa `params`. Pembacaan
   `(await context.params).id` melempar sebelum dispatch service. Direproduksi GET daftar,
   GET kebijakan dan POST kebijakan pada aplikasi lokal, DB disposable dan login normal.
   Route statis kini tidak membaca ID; route dinamis tetap memakai ID. Tes factory kini
   menyertakan context kosong seperti Next. Tidak menyimpulkan penyebab di VPS sama.
3. **Sprin Penugasan:** nilai `SPRIN_ASSIGNMENT` diterima di tipe domain, validasi service,
   Zod/multipart dan UI/detail/histori. Kolom `sprinNumber` tetap opsional dan terpisah.
   Constraint SQL diperluas melalui migration forward; aturan eligibility/quota/credit/saldo,
   duplikasi dan approval tidak diubah.
4. **Izin:** API/database disposable awal benar-benar kosong, HTTP 200; select memang
   dinonaktifkan dan menjelaskan tidak ada jenis aktif serta mengarahkan ke Admin. Dengan
   fixture jenis aktif berlabel simulasi, select dan simpan draf berfungsi. Loading, HTTP503
   dan kegagalan jaringan diuji secara terpisah melalui intersepsi yang diberi label.
   Tidak menambah seed/katalog/kebijakan atau melewati validasi aktif di server. Katalog
   operasional tetap perlu sumber/keputusan instansi dan konfigurasi master yang sah.
5. **Penanda:** Admin melihat scan yang terikat pada keputusan (bukan otomatis versi terbaru),
   jumlah halaman, ukuran area terlihat dan rotasi. GET metadata pada endpoint preview memakai
   otorisasi Admin, checksum sumber dan private/no-store. Preview sumber serta hasil memiliki
   tautan tab baru. Preview inline native ditemukan kosong pada mobile headless; kini halaman
   dirender dengan PDF.js, dapat diperbesar dan penyimpanan diblokir jika render gagal. Penanda kini menampilkan status, Admin pencatat dan waktu snapshot pada
   minimum 7 pt; posisi terlalu kecil ditolak. Crop yang melampaui media dibatasi pada irisan
   area yang benar-benar terlihat. Admin tetap harus memastikan isi/tanda tangan tidak tertutup;
   tidak ada deteksi OCR atau janji posisi otomatis aman untuk semua scan.
   Edisi baru memakai renderer `form-stamp-v2`; edisi lama tetap byte-identik/dapat diunduh,
   dan replay penyimpanan edisi lama tidak merender ulang. Preview lama yang belum disimpan
   perlu dibuat ulang setelah upgrade. Halaman scan bertanda berada di depan, **diikuti
   ringkasan tambahan** (dapat beberapa halaman jika alasan panjang).
6. **TTE:** tidak ditemukan integrasi penyedia. Penanda adalah catatan SI CUTI, bukan tanda
   tangan elektronik/cap pejabat. [Catatan desain TTE](tte-integration-design.md) memisahkan
   pejabat, pencatat, verifikasi penyedia, keutuhan, versi dan pertanyaan kewenangan.

## Migration, dependency dan rollout

Migration baru: `20261027090000_sprin_assignment`. Tidak mengubah migration lama,
kolom/tabel/saldo atau data existing. Penggantian CHECK dilakukan dalam transaksi singkat
sebagai NOT VALID, kemudian divalidasi; semua jenis lama tetap valid. Migrator perlu hak
ALTER/ownership pada `JointLeaveClaim`; app tidak memerlukan grant baru. Dependency baru `pdfjs-dist` **6.4.299** dikunci di package/lockfile untuk preview canvas
lintas browser; Apache-2.0, engine Node >=22.13 / >=24 kompatibel Node 24 proyek. Aset worker,
CMap, font, WASM dan profil warna disalin saat `dev`/`build` oleh
`scripts/prepare-pdf-preview.mjs`, disajikan same-origin tanpa CDN. Docker runtime sudah menyalin
`public` dari builder sehingga aset ikut image; tidak perlu grant atau secret baru. Aset generated
diabaikan git/lint/formatter. PDF.js dirender lazy dan task dibersihkan saat halaman/preview berganti;
konfirmasi/simpan tetap nonaktif bila render gagal. Preview memiliki perbesaran hingga 300%.
Pengukuran font formulir memakai `pdf-lib` yang sudah ada.

`npm audit --omit=dev` melaporkan 19 temuan (1 critical, 13 high, 5 moderate) pada dependency
baseline yang tidak diubah. Audit lockfile sumber memberi hitungan dan daftar package terdampak
yang sama; tidak ada package terdampak baru/PDF.js pada laporan. Tidak melakukan upgrade besar
Prisma/Next/dependency lain di luar scope UAT; temuan baseline tetap perlu tindak lanjut keamanan.

Operator, setelah review/approval rollout terpisah:

1. Backup database dan arsip privat; verifikasi lingkungan, role, volume dan SHA image.
2. Terapkan migration forward dengan migrator yang benar, pastikan constraint tervalidasi dan
   privileges app existing tetap tersedia. Validasi memakai scan tabel; jadwalkan sesuai beban.
3. Jalankan app dari HEAD PR yang disetujui, health check dan smoke dengan sesi sah: jenis lama,
   Sprin, kebijakan, izin aktif/kosong, scan versi terpilih, preview/save dan arsip lama.
4. Rollback tidak boleh menghapus/mengganti jenis Sprin pada histori. CHECK yang lebih longgar
   dapat dibiarkan; versi aplikasi lama belum mengenal label/nilai baru dan bukan rollback
   fungsional aman setelah record Sprin dibuat. Gunakan versi rollback yang tetap mengenal
   `SPRIN_ASSIGNMENT` atau hentikan pengajuan baru sambil memperbaiki maju. Tidak menurunkan
   constraint sebelum audit record baru; tidak mengubah keputusan lama untuk memaksanya lolos.

Tidak merge/deploy/menutup issue. Perangkat Safari/iPad asli belum diuji. Keluhan spesifik
pengguna belum memiliki screenshot/data pemicu; temuan lokal dan contoh sintetis tidak
membuktikan semua keluhan tersebut selesai. Screenshot/contoh pemicu tetap diperlukan untuk
bagian yang belum dapat dipetakan ke reproduksi lokal.

Harness produksi `tests/browser/uat-forms-claims.mjs` mensyaratkan DB **lokal kosong**
`si_cuti_browser`, acknowledgement disposable, migration dan server di port 3200. Fixture akun
memakai service existing, password acak hanya dalam memori, login normal lewat UI; bukan cookie
injection. Konfigurasi saldo/jenis izin adalah fixture DB sintetis. Kebijakan, klaim, bukti,
review, approval, arsip dan edisi melewati API asli; pemilihan izin/simpan draf serta pemilihan
halaman/preview/konfirmasi edisi juga lewat UI. Konfigurasi/pengiriman/review klaim diuji lewat
API dengan sesi nyata, bukan klik seluruh langkah UI. Tiga fault izin (loading, HTTP503,
jaringan abort) memakai intersepsi yang jelas, bukan klaim kegagalan operasional alami.
`NODE_ENV=test` untuk server lokal memakai kebijakan cookie pengujian existing.

Contoh seluruhnya sintetis, scan diberi label **tanpa tanda tangan asli**; tidak membuat tanda
tangan palsu. Semua halaman contoh PDF diperiksa lewat render; posisi marker diuji dalam area
kosong formulir contoh, namun pilihan posisi scan lain tetap harus diperiksa Admin.
